About Tartarus

Tartarus is a local-first active-recall language trainer. Learning material remains in JSON files; SQLite stores learner progress, session history, Leitner state, and append-only mastery milestones that anchor each word's Consolidation Track schedule. The Web UI binds only to the local machine.

One guided path

Practice has one entry point. Tartarus chooses the work from the learner state instead of exposing optional learning modes or mastery shortcuts. Two tracks feed that one entry point: the 10-Day Consolidation Track (acquisition and retrieval practice) and Spaced Maintenance (spaced review of what's already mastered). Whatever is due from previous days always comes first — starting a session is the only decision a learner makes, and due review is served before any new or continuing Consolidation Track material, every time. Only once nothing is due does the same entry point continue the Consolidation Track. Every due per-word reinforcement cohort comes first (a scaffolded warm-up), then due Spaced Maintenance (unscaffolded pure recall), then Encoding. When the selected material has no work ready, the entry button is disabled and setup directs the learner to choose other material instead of reopening completed same-day work.

Setup itself is decision-free: pick a language, a level, and a part of speech, and the exact word list resolves on its own — there is no separate “which file” step. Nothing earned is ever lost or undone: a score only ever moves up in fixed steps or holds still, a wrong answer costs a bounded corrective drill rather than a setback, and progress made today resumes from exactly where it was left, tomorrow or any day after. A word that reaches band 5 today is still at band 5 tomorrow; if it crosses band 9, its own mastery date starts its 10-day track and it enters Leitner Box 1 in the same step. It does not wait for the rest of the file. Finishing the remaining Encoding pool is a question of how much you practice, not chance — there's no cap on sessions in one sitting.

Days 1–10 are derived independently for every mastered word from its append-only mastery date. Different cohorts can occupy different stages in the same file and session. Extra practice cannot move a word into tomorrow's stage, and after Day 10 that word remains in Spaced Maintenance.

The stage sequence follows how memory actually consolidates: initial encoding, then retrieval practice at increasing difficulty (cued, then effortful, then free recall), then reconsolidation under a stricter reverse-production constraint, ending in automaticity — the skill becomes fast and effortless — before handing off to long-term Spaced Maintenance.

  • Day 0 — Encoding: focused score acquisition until every active item reaches 9.0.
  • Days 1–2 — Cued Recall: heavily masked prompts with automatic speech.
  • Days 3–4 — Effortful Retrieval: fully masked prompt with automatic speech and two consecutive correct productions.
  • Days 5–6 — Free Recall: definition recall, automatic speech, response timer at 0.75s per character.
  • Days 7–8 — Reconsolidation: reverse production, automatic speech, response timer at 0.5s per character.
  • Days 9–10 — Automaticity: reverse production, automatic speech, response timer at 0.5s per character.

Every mastered word follows Days 1–10 from its own mastery date; corrected mistakes add drill work but never reset that clock. Spaced Maintenance continues through Box 10 on its own schedule. The stronger learning-complete milestone requires every active item to have left Encoding and the ten-day track and to have reached Leitner Box 10.

Exact writing

Answers are compared with the dataset target exactly. Case, punctuation, spaces, articles, commas, and form order all matter. For example, if the target is das Buch, die Bücher, that complete string is required.

Mistakes and corrective drills

A wrong answer records the mistake once and requires nine consecutive correct repetitions before progress resumes. Only the temporary drill streak can reset: score, mastery date, and Leitner box never move backward. Completing the drill grants the same single forward transition as a correct first answer. Effortful Retrieval normally requires two productions, but any mistake escalates that item to the full nine-answer drill. The drill is session-local, creates no future mistake debt, and cannot be skipped through normal application controls.

Audio and interaction

The prompt itself is the writing surface: visible prompt letters stay dim, masked positions remain as gaps, and the characters you type illuminate or fill those positions in place. There is no separate answer box and no live correctness hint; Enter submits the exact string for evaluation. Speech uses the local macOS say command. Audio is never muted: every stage plays its prompt automatically and Replay always works. While speech is running, typing into the word remains available and is preserved, but Enter, Replay, End session, navigation, and card changes remain blocked until speech completes.

Progress and reports

Reports show factual history: session time, answers, drills, Consolidation Track score progress, Consolidation Track state, Leitner box distribution, maintenance readiness, historical incorrect-answer counts, and cumulative mastery and Box-10 milestone charts. The charts use append-only database events. Material mastered before event tracking may begin later on the chart because older dates are included only when the original milestone date is still reliable; Tartarus never fabricates a historical date. Historical mistakes are not pending drills, and score 9 alone is not presented as complete learning.

Word lists

Use the tab to create personal material or edit an existing list. Shared source JSON is not overwritten by personal edits; personal overrides retain stable item identities and untouched fields. Once a list is loaded there, Restart progress for this list is available — a deliberate, confirmed action that resets that list's scores and Leitner boxes and clears its mastery milestones for a fresh pass, while leaving session/time history untouched as a record. It lives here, not in daily Practice, since it is not something the guided flow should ever suggest on its own.

Keyboard-friendly

Enter submits an answer and also activates the main setup/summary flow when appropriate. Esc ends an ordinary active session, but is deliberately unavailable while a mandatory corrective drill is active.
